# Personal Expense Assistant

## Overview

This project demonstrates three different approaches for solving the same private-data problem: a Personal Expense Assistant.

The system works with personal expense records containing the date, category, description, and amount.

The three approaches implemented are:

1. Plain Chatbot
2. Rule-Based Workflow
3. AI Agent
